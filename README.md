Palmera Bay is a complete open-world crime game set in an original sun-soaked coastal city: explore on foot and by car, steal cars, outrun the police across a 5-star wanted system, fight rival crews, and pull six story missions up to the Palmera Score — with traffic, pedestrians, a minimap HUD, synthesized sound and music, and localStorage saves. Every city, character, vehicle, name, story, piece of art and sound is original, drawn on canvas and synthesized with WebAudio; nothing is taken from any commercial game.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
